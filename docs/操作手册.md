## 1. 系统简介

### 1.1 产品概述

Geniview AI 是一款面向生产/工序视频的**动作分析与标注平台**。系统通过集成 Kimi (Moonshot AI)、Qwen、Gemini 等大模型，对上传的视频进行智能分析，识别并标注出视频中各动作段落，生成包含动作时间轴、置信度、改善建议等内容的结构化报告。

### 1.2 核心功能

| 功能模块 | 说明 |
|---------|------|
| **视觉检测** | 上传视频 → AI 自动分析 → 生成动作标注与统计结果 |
| **结果查看** | 视频回看、动作列表展示、时间轴导航、统计图表、深度诊断 |
| **结果修订** | 对 AI 识别出的动作进行增删改，支持回写 Markdown/JSON |
| **用户管理** | 管理员可创建/编辑用户，配置各用户的模型与 API Key |
| **双语输出** | 支持中文分析结果自动翻译为英文 |
| **Docker 部署** | 支持一键容器化部署，适配生产环境 |

### 1.3 系统架构

系统采用 **静态前端 + Python HTTP 服务 + AI 分析引擎** 的三层架构：

- **前端**: HTML / CSS / JavaScript (Chart.js 图表)
- **服务端**: Python `http.server` 提供 API 与静态资源
- **分析引擎**: `main.py` 集成多模型 AI 调用
- **数据库**: MySQL / SQLite 自动切换
- **文件存储**: `data/` (原始视频)、`result/` (分析结果)

## 8. 费用计算器

> **注意**: 本功能仅对管理员角色开放。

### 8.1 进入费用计算器

管理员登录后，左侧导航栏显示【费用计算器】入口。点击进入。

### 8.2 费用估算

系统根据视频时长、采样帧率、模型单价，自动估算 Token 费用。

**计算公式说明**:

1. 采样帧数 `N = ceil(视频时长 × fps)`
2. 视觉输入 Tokens `V = N × k` (k 为每帧视觉 Token 估算系数，默认 258)
3. 输入 Tokens `In = V + P` (P 为提示词固定 Tokens)
4. 计费输出 Tokens `Out_bill = Out + Think`
5. 输入费用 `C_in = In / 1e6 × price_in`
6. 输出费用 `C_out = Out_bill / 1e6 × price_out`
7. **总费用 `C = C_in + C_out`**

## 9. 常见问题

### Q1: 登录失败，提示"用户名或密码错误"

**解决方法**:  
- 确认用户名和密码是否正确（默认管理员: `admin` / `geniviewa`）
- 检查键盘大小写是否开启
- 若遗忘密码，需联系管理员重置或直接在数据库中修改密码散列

### Q2: 视频上传进度卡住不动

**解决方法**:  
- 检查网络连接是否稳定
- 刷新页面后重新上传
- 检查 `data/` 目录是否有写入权限
- 对于超大文件，可尝试压缩后再上传

### Q3: 检测任务长时间没有进度更新

**解决方法**:  
- 检查 API Key 是否有效且余额充足
- 查看日志面板中的错误信息
- 确认所选模型服务是否正常可用
- 尝试切换其他模型重新检测

### Q4: 结果页面无法加载视频

**解决方法**:  
- 确认视频文件是否存在于 `data/` 目录
- 检查浏览器是否支持该视频格式 (推荐 MP4/H.264)
- 刷新结果列表后重试

### Q5: 数据库连接失败

**解决方法**:  
- 系统会自动回退到 SQLite，无需手动干预
- 如需使用 MySQL，请确认 MySQL 服务已启动，且配置信息正确
- 检查 `app_config.py` 中的数据库连接参数
